# claude-projects

Small Claude-adjacent automations and scripts, one folder per project.

| Project | What it does | Status |
|---|---|---|
| [`daily-inbox-briefing`](./daily-inbox-briefing) | Gmail triage → iMessage summary → Notion to-dos, via a Claude Cowork scheduled task | Retired — superseded by Cowork's native daily briefing |
| [`gmail-brief`](./gmail-brief) | Standalone Python script: Gmail → Claude summary → prioritized email brief, cron-scheduled | Portfolio / demo — not actively run |
| [`video-edit-autopilot`](./video-edit-autopilot) | Raw video → style-matched cut → branded + captioned + delivered (video, audio, captions, transcript). Merges `podcast-audio-autopilot-kit` and the usable (non-Editkin) parts of `video-autopilot-kit` into one pipeline | Active — new, smoke-tested against synthetic footage |
